# Práctica V · Anexo II — Consultas SQL sobre la BD de Steam

Consultas sobre la tabla de ~13 000 juegos de Steam, con capturas de los resultados y un PDF final.

## Estructura
```
bd/             script o volcado de la base de datos steam
consultas/      un .sql por bloque de consultas (01-10, 11-20, 21-30, subconsultas)
capturas/       capturas de pantalla de cada resultado (consulta_01.png, ...)
documentacion/  PDF final con enunciado, consulta y captura
```
